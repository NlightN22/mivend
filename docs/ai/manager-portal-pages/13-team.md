# Страница: Team (`/team`)

> Прочитай сначала `00-shared-conventions.md`.

## Назначение

Просмотр оргструктуры компании (отделы, сотрудники, должности) — данные приходят из 1С, здесь в основном **просмотр**, не полноценный CRUD. Единственное реальное действие — перенос клиента от одного менеджера к другому.

## Структура контента

1. Заголовок "Team".
2. Список/дерево подразделений слева (или таб-переключатель сверху): Sales, Purchasing, Security, Executive — при выборе подразделения справа показывается таблица сотрудников этого отдела.
3. **DataTable** сотрудников выбранного отдела, столбцы:
    - Name
    - Position / должность
    - Branch (филиал/точка, если применимо)
    - Role badge (Manager / Dept Head / и т.д. — переиспользуй бейджи ролей из `00-shared-conventions.md`)
    - Assigned clients (число — только для Manager, кликабельно → `/customers` с фильтром по этому менеджеру)
4. Кнопка "Reassign clients" (видна только Sales Dept Head/Portal Admin — подпиши это комментарием в файле) — открывает модалку: select "From manager" → select "To manager" → список клиентов первого с чекбоксами → кнопка "Move selected".

## Состояния

Пустое состояние не характерно (оргструктура почти всегда заполнена), но добавь заглушку "No employees in this department yet" на случай.
