# Страница: Customers — список (`/customers`)

> Прочитай сначала `00-shared-conventions.md`.

## Назначение

Список клиентов/контрагентов, доступных текущему пользователю. Это CRM-подобный список, не только справочник — отсюда видно ключевые коммерческие показатели по каждому клиенту.

## Кто видит что

- **Manager**: только свои клиенты (закреплённые за ним).
- **Operator, Dept Head**: все клиенты своего подразделения/отдела.
- **General Director, Security Officer**: все клиенты компании.

Сделай концепт для роли **Manager** — типичный сценарий, небольшой список "своих" клиентов.

## Структура контента

1. Заголовок "My Clients" (именно "My", так как для Manager это его личный список — для других ролей заголовок был бы просто "Customers", отметь это комментарием в файле).
2. **FilterBar**: поиск по имени/ИНН, select "Status" (Active/Inactive), кнопка "Reset".
3. **DataTable**, столбцы:
    - Company name (кликабельно → `/customers/:id`)
    - Contact person
    - Credit limit
    - Credit balance (текущая задолженность/использование лимита — можно как мини progress bar)
    - Active discounts (число активных установок скидок — если >0, бейдж, кликабельно → `/discounts` с фильтром по клиенту)
    - Last order date
4. Кнопка сверху таблицы "Reassign manager" (доступна только Sales Dept Head/Portal Admin — отметь комментарием, для Manager её быть не должно).

## Состояния

EmptyState "You don't have any assigned clients yet" — актуально для нового менеджера.

## Переходы

Клик по строке → `/customers/:id`.
