# Страница: Dashboard (`/`)

> Прочитай сначала `00-shared-conventions.md` — общий стиль и layout.

## Назначение

Главная страница после входа. Показывает сводку, релевантную роли текущего пользователя — разную для каждой роли (это не один универсальный дашборд, содержимое меняется в зависимости от того, кто вошёл).

## Кто видит что

- **Operator**: метрики по своему подразделению/точке — заказы в работе, просроченные заказы, новые клиенты за период.
- **Manager**: метрики по своим клиентам — активные заказы, статус поданных заявок на согласование (сколько на рассмотрении, сколько одобрено/отклонено за период).
- **Sales Dept Head / Purchasing Dept Head / General Director**: сводка по компании/отделу + счётчик заявок, ожидающих решения именно этого пользователя, с прямой кнопкой-ссылкой на `/approvals`.

Сделай HTML-концепт **для роли Manager** как основной вариант (самая частая роль), но добавь текстовый комментарий-заметку вверху файла (или в HTML как `<!-- comment -->`), что для Director/Dept Head набор карточек другой (акцент на approvals-очереди).

## Структура контента

1. Заголовок: "Welcome back, {Manager Name}" + текущая дата.
2. Ряд карточек-метрик (KPI tiles), 3-4 штуки в ряд:
    - Active orders (число)
    - Orders awaiting shipment / overdue (число, акцентный цвет если >0)
    - Pending approval requests initiated by me (число, кликабельно → `/approvals`)
    - My clients (число, кликабельно → `/customers`)
3. Ниже — два блока side-by-side:
    - **Recent orders** — компактная таблица последних 5 заказов (номер, клиент, статус, сумма, дата).
    - **My approval requests status** — компактный список последних 3-5 поданных заявок с их текущим статусом/шагом (например "Discount request #123 — waiting on Purchasing Dept Head").
4. Если у пользователя есть скидки, которые скоро истекут (`/discounts`, статус "Expiring soon") — отдельный предупреждающий баннер сверху страницы (жёлтый/оранжевый) со списком 1-3 таких скидок и ссылкой на `/discounts`.

## Состояния

- Пустое состояние для "Recent orders" / "My approval requests" — если у нового сотрудника пока ничего нет.
- Баннер про истекающие скидки показывается только если такие есть — не показывай его в примере, если хочешь продемонстрировать "чистое" состояние, но лучше включи для демонстрации механизма grace period.

## Переходы

Каждая KPI-карточка и каждая строка в мини-таблицах кликабельна и ведёт на соответствующую страницу (`/orders`, `/approvals`, `/customers`, `/discounts`).
