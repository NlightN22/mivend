# Страница: Customer detail (`/customers/:id`)

> Прочитай сначала `00-shared-conventions.md`.

## Назначение

Полная карточка клиента-контрагента: реквизиты, коммерческие условия, история, документы, активные скидки.

## Структура контента

1. Хлебная крошка: "Customers / {Company name}".
2. Шапка: название компании, ИНН, статус (Active/Inactive), ответственный менеджер (с возможностью сменить — кнопка "Reassign", видна только Sales Dept Head/Portal Admin).
3. Табы или секции подряд на странице (выбери сам, что нагляднее для черновика — предпочтительно табы, чтобы не растягивать страницу):
    - **Overview**: контакты (телефон/email/адрес), кредитный лимит, текущий баланс, дата регистрации.
    - **Orders**: компактная таблица заказов этого клиента (переиспользуй визуальный стиль из `02-orders-list.md`, без колонки "Customer" — она тут не нужна).
    - **Discounts**: список активных и истёкших установок скидок для этого клиента (переиспользуй стиль StatusBadge: Active / Expiring soon / Expired), с кнопкой "New discount grant" → ведёт к форме подачи заявки на `/discounts`.
    - **Documents**: список документов клиента (счета, договоры, акты) — тот же список, что показан бы в `/documents` с фильтром по этому клиенту.
4. Кнопка "Request price adjustment" где-то в шапке или на вкладке Overview — открывает форму/модалку подачи заявки на разовую корректировку цены (см. `08-pricing.md`).

## Состояния

Если у клиента нет заказов/скидок/документов — EmptyState на соответствующей вкладке.
