# Страница: Profile (`/profile`)

> Прочитай сначала `00-shared-conventions.md`.

## Назначение

Личные настройки текущего пользователя — минимальная, но необходимая страница в любом портале. Доступна всем ролям, содержимое одинаковое независимо от роли.

## Структура контента

1. Заголовок "Profile Settings".
2. Блок "Account info" (в основном read-only, приходит из ERP-оргструктуры — см. `13-team.md`): имя, email, должность, подразделение, филиал.
3. Блок "Security": форма смены пароля (текущий пароль, новый, подтверждение).
4. Блок "Preferences": простые переключатели — например язык интерфейса (если понадобится в будущем), плотность отображения таблиц.

## Состояния

Обычная форма настроек, без сложных состояний — стандартное подтверждение toast'ом при сохранении ("Profile updated").

## Примечание

Это сознательно самая простая/малодетализированная страница всего портала — не нужно усложнять её сверх обычного стандарта account-settings.
