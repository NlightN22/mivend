# Страница: Profile (`/profile`)

> Прочитай сначала `00-shared-conventions.md`.

## Назначение

Личные настройки текущего пользователя — минимальная, но необходимая страница в любом портале. Доступна всем ролям, содержимое одинаковое независимо от роли.

## Структура контента

1. Заголовок "Profile".
2. Блок "Account": имя, e-mail, роль (только чтение).
3. Блок "Preferences": язык интерфейса (ru / en) и тема (светлая / тёмная / авто); хранятся в браузере.
4. Раздел "Security": двухфакторная аутентификация, письмо о входе с нового устройства, активные сеансы, смена пароля, выход на всех устройствах.

Пароль, двухфакторная защита и сеансы раньше жили в системных настройках (`/settings/security`); теперь только здесь. Меню пользователя ведёт на `/profile` и содержит только личные пункты, системные настройки открываются из бокового меню (#361).

## Состояния

Обычная форма настроек, без сложных состояний — стандартное подтверждение toast'ом при сохранении ("Profile updated").

## Примечание

Это сознательно самая простая/малодетализированная страница всего портала — не нужно усложнять её сверх обычного стандарта account-settings.
